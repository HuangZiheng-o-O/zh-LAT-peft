# Gated Linear Attention (GLA) – Principles & Implementation Map

## 1. Key Ideas from `2312.06635v6.md`
- **Recurrent gating for forgetting.** GLA augments linear attention with a time-varying 2D gate so that each head updates \( \mathbf{S}_t = (\boldsymbol{\alpha}_t^\top \mathbf{1}) \odot \mathbf{S}_{t-1} + \boldsymbol{k}_t^\top \boldsymbol{v}_t \), giving Transformer-like layers the ability to forget stale context similar to gated RNNs (`2312.06635v6.md:241`, `2312.06635v6.md:269`).
- **Parallel form via cumulative products.** Defining \( \boldsymbol{b}_t = \prod_{j \le t} \boldsymbol{\alpha}_j \) enables an attention-style computation \( \mathbf{O} = ((\mathbf{Q} \odot \mathbf{B})(\mathbf{K}/\mathbf{B})^\top \odot \mathbf{M})\mathbf{V} \), but stability requires evaluating the ratios in log space (`2312.06635v6.md:305`). The chunkwise decomposition introduces inter-chunk decay terms \( \Lambda, \Gamma, \gamma \) to move information between chunks efficiently (`2312.06635v6.md:316`).
- **Hardware-friendly tiling and gradients.** Secondary tiling lets most inter-sub-chunk matmuls run in half precision while only the log-space intra-sub-chunk blocks stay in fp32, yielding tensor-core utilization without sacrificing numerical stability (`2312.06635v6.md:324`). A closed-form gradient \( \mathrm{d}\log \boldsymbol{\alpha}_t = \sum_{i \ge t} (\boldsymbol{q}_i \odot \mathrm{d}\boldsymbol{q}_i - \boldsymbol{k}_i \odot \mathrm{d}\boldsymbol{k}_i) \) avoids storing \( L \times d \times d \) hidden states (`2312.06635v6.md:332`).
- **Multi-head Transformer recipe.** Each head keeps its own matrix state \( \mathbf{S}_t^h \), LayerNorm is applied per head before concatenation, a Swish gate \( \boldsymbol{r}_t \) modulates the combined output, and the residual stack mirrors LLaMA blocks with SwiGLU FFNs (`2312.06635v6.md:340`, `2312.06635v6.md:346`). Gate logits use a low-rank projection with temperature \( \tau=16 \) to slow forgetting while keeping the parameter count near \( 4d^2 \) (`2312.06635v6.md:352`).
- **Empirical behavior.** GLA matches or exceeds Transformer++, RetNet, and Mamba on SlimPajama-scale language modeling, shines on recall-heavy tasks, and extrapolates beyond training length when combined with TBPTT over long contexts (`2312.06635v6.md:366`, `2312.06635v6.md:408`).

## 2. Code Architecture in `3rdparty/flash-linear-attention/fla`

### 2.1 Layer & gating pipeline
- **`GatedLinearAttention` orchestrates projections and kernel choice.** The class builds q/k/v linear maps, optional short convolutions, the low-rank gate projector, and output gating/norm logic while exposing modes `chunk`, `fused_chunk`, and `fused_recurrent` (`3rdparty/flash-linear-attention/fla/layers/gla.py:23`). Short convolutions can maintain per-layer caches for streaming inference (`3rdparty/flash-linear-attention/fla/layers/gla.py:200`).
- **Gate logits live in log space.** Hidden states go through `gk_proj`, then `F.logsigmoid` and optional clamping divided by `gate_logit_normalizer`, yielding numerically stable log-gates fed to the kernels (`3rdparty/flash-linear-attention/fla/layers/gla.py:150`, `3rdparty/flash-linear-attention/fla/layers/gla.py:236`). This mirrors the paper’s cumulative-product formulation and enforces the temperature idea from §4.4.
- **Runtime mode switching & caching.** The layer automatically falls back to the lighter `fused_recurrent` kernel for sequences ≤64 tokens while longer batches use the configured chunk variant; recurrent and convolutional states are packed into the `Cache` object so autoregressive decoding has O(1) per-token cost (`3rdparty/flash-linear-attention/fla/layers/gla.py:188`, `3rdparty/flash-linear-attention/fla/layers/gla.py:243`, `3rdparty/flash-linear-attention/fla/layers/gla.py:276`).
- **Output gating & normalization.** After kernel outputs, each head runs through RMSNorm (optionally fused) and an elementwise output gate before the final projection, reproducing the multi-head equations from the paper (`3rdparty/flash-linear-attention/fla/layers/gla.py:284`).

### 2.2 Kernel stack
- **Log-domain prefix products.** `chunk_local_cumsum` computes forward or reverse cumulative sums over log-gates so every chunk knows both the decay from its start and to its end, implementing the paper’s \( \Lambda/\Gamma \) factors without recomputing exponentials for every tile (`3rdparty/flash-linear-attention/fla/ops/utils/cumsum.py:429`).
- **`chunk_gla` (reference kernel).** `chunk_gla_fwd` builds cumulative gates, runs a recurrent sweep per chunk to obtain hidden states, materializes intra-chunk attention blocks \( A \), and merges them for the final output; its backward pass reuses the same utilities and derives gradients w.r.t. q/k/v/g without storing the full state trajectory (`3rdparty/flash-linear-attention/fla/ops/gla/chunk.py:1051`, `3rdparty/flash-linear-attention/fla/ops/gla/chunk.py:1102`). `ChunkGLAFunction` wraps the Triton kernels, dynamically selects a power-of-two chunk size, and decides whether to recompute `g_cumsum` in backward (`3rdparty/flash-linear-attention/fla/ops/gla/chunk.py:1192`). The user-facing `chunk_gla` handles seqlen padding, optional initial states, and `cu_seqlens` packs for variable-length batches (`3rdparty/flash-linear-attention/fla/ops/gla/chunk.py:1256`).
- **`fused_chunk_gla` (fast path).** `FusedChunkGLAFunction` fuses inter- and intra-chunk logic: it first converts q/k into decay-aware tensors, dispatches the Triton forward kernel that streams states chunk-by-chunk while accumulating final states, and computes intra-chunk contributions via tiled matmuls; backward recomputes the gated tensors and launches dedicated kernels for dq/dk/dv/dg (`3rdparty/flash-linear-attention/fla/ops/gla/fused_chunk.py:362`, `3rdparty/flash-linear-attention/fla/ops/gla/fused_chunk.py:384`, `3rdparty/flash-linear-attention/fla/ops/gla/fused_chunk.py:417`). The public wrapper pads sequences to multiples of the chunk size, warns about head-first layouts, and trims the output afterward (`3rdparty/flash-linear-attention/fla/ops/gla/fused_chunk.py:609`).
- **`fused_recurrent_gla` (autoregressive mode).** This adapter plugs GLA gates into the general fused recurrent kernel for small or streaming contexts, supports `cu_seqlens`, exposes `initial_state`/`final_state`, and keeps inference purely sequential when necessary (`3rdparty/flash-linear-attention/fla/ops/gla/fused_recurrent.py:11`).

### 2.3 Simplified variant
- **Head-wise gating baseline.** `SimpleGatedLinearAttention` swaps the elementwise gate for a head-wise scalar gate so it can reuse RetNet-style kernels; it shares most projections with the main layer but is restricted to the chunk kernel (`3rdparty/flash-linear-attention/fla/layers/simple_gla.py:20`). The accompanying README summarizes the trade-off: faster matmul-based kernels with less expressive gating, matching the head-wise mechanisms from Gated RFA/Mamba2/YOCO (`3rdparty/flash-linear-attention/fla/ops/simple_gla/README.md:1`).

### 2.4 Model scaffolding
- **Transformer block integration.** `GLABlock` wires RMSNorm → GLA (or hybrid attention layers) → SwiGLU MLP with residual connections, mirroring the architecture described in §4.4 and enabling selective replacement of layers with standard attention if desired (`3rdparty/flash-linear-attention/fla/models/gla/modeling_gla.py:35`).
- **Full model & generation wrapper.** `GLAModel` stacks `GLABlock`s atop token embeddings and a final RMSNorm, manages caches/output flags, and is wrapped by `GLAForCausalLM` for language modeling plus HF generation utilities via `FLAGenerationMixin` (`3rdparty/flash-linear-attention/fla/models/gla/modeling_gla.py:171`, `3rdparty/flash-linear-attention/fla/models/gla/modeling_gla.py:259`).
- **Configuration surface.** `GLAConfig` exposes hyperparameters for expansion ratios, number of heads, gating options, convolutional prefilters, hybrid attention injections, fused kernels, and loss-layer choices—mirroring the paper’s parameter allocation discussion (`3rdparty/flash-linear-attention/fla/models/gla/configuration_gla.py:7`).

## 3. Practical Notes for Future Work
- **Gate scaling mirrors the paper’s temperature trick.** `gate_logit_normalizer` and the low-rank `gk_proj` let you tune how aggressively information decays; lowering the normalizer speeds forgetting, while increasing it approaches the constant-decay RetNet regime (`3rdparty/flash-linear-attention/fla/layers/gla.py:150`, `2312.06635v6.md:352`).
- **Select kernel mode based on sequence profile.** The layer already prefers `fused_recurrent` for ≤64 tokens, but for long contexts you can toggle between `chunk` (more general, supports padding packs) and `fused_chunk` (highest throughput when sequences are uniform). Both accept `initial_state` so TBPTT over 2K segments—as suggested in the paper for 24K training—only needs the final state passthrough (`3rdparty/flash-linear-attention/fla/layers/gla.py:188`, `3rdparty/flash-linear-attention/fla/ops/gla/chunk.py:1256`, `2312.06635v6.md:408`).
- **Mind cached state shapes.** The recurrent state has shape `[batch_or_num_seqs, H, d_k/H, d_v/H]`; storing it in `Cache` lets generation reuse states, but when you mix variable-length inputs you must present flattened batches and matching `cu_seqlens` to the kernels (`3rdparty/flash-linear-attention/fla/layers/gla.py:243`, `3rdparty/flash-linear-attention/fla/ops/gla/fused_recurrent.py:24`).
- **Simple GLA is a speed/quality knob.** Swapping to `SimpleGatedLinearAttention` reduces the gating expressiveness to scalar per head (matching Eq. 3 with \(\gamma_t\) scalars) but allows relying entirely on matmul kernels; the README explicitly positions it as a baseline so it can be handy for ablations or fast sanity checks before moving to full GLA (`3rdparty/flash-linear-attention/fla/layers/simple_gla.py:20`, `3rdparty/flash-linear-attention/fla/ops/simple_gla/README.md:5`).
- **Testing & debugging hooks.** Because gradients for log-gates are derived analytically, look for bugs in the `chunk_local_cumsum` and `chunk_gla_bwd` stages first if training diverges—errors there would directly corrupt `d\log \alpha_t` (`3rdparty/flash-linear-attention/fla/ops/utils/cumsum.py:429`, `3rdparty/flash-linear-attention/fla/ops/gla/chunk.py:1102`, `2312.06635v6.md:332`).
