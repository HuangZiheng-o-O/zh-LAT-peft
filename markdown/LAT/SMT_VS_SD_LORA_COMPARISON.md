## 1. 设计理念对比

### 1.1 核心思想

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        SMT vs SD-LoRA 设计理念                              │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  SMT (Sparse Matrix Tuning):                                               │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  "直接在原权重上选择稀疏子矩阵进行微调"                               │   │
│  │                                                                     │   │
│  │  W = W₀ + ΔW_M  (ΔW_M是稀疏的，仅在选中的子矩阵上有梯度)              │   │
│  │                                                                     │   │
│  │  关键: 找到最重要的子矩阵 → 只更新这些矩阵                          │   │

│  │                                                                     │   │
│  │  每个维度属于: {Train, Freeze, Zero}                                 │   │
│  │                                                                     │   │
│  │  关键: 梯度重要性排序 → 分配到三类                                  │   │

└─────────────────────────────────────────────────────────────────────────────┘

## 2. 技术实现对比

### 2.1 Warmup阶段

```python
# ============================================================================
# SMT Warmup
# ============================================================================
# 目标: 收集梯度用于子矩阵选择
for iter in range(full_ft_steps):  # 默认100次
    loss = model(batch)
    loss.backward()  # 全量反向传播

    # 累积每个256×256块的梯度
    for (module, layer), grad_accum in warmup_grads.items():
        grad_accum += param.grad.detach().cpu()

# 选择: 对所有块排序，选择Top-K
selected_blocks = select_top_k_blocks(warmup_grads, num_submatrix)


# ============================================================================
# SD-LoRA Warmup
# ============================================================================
# 目标: 收集梯度用于维度分类
for iter in range(num_warmup_it):  # 默认100次
    loss = model(batch)
    loss.backward()  # 全量反向传播

    # 累积每个channel的梯度
    sdlora_grad_accum[param] += get_channel_gradients(param.grad)

# 选择: 对channel排序，按比例分配到三类
num_zero = int(d * zero_ratio)      # 10%
num_freeze = int(d * freeze_ratio)  # 50%
num_train = d - num_zero - num_freeze # 40%

sorted_channels = argsort(sdlora_grad_accum)
zero_channels = sorted_channels[:num_zero]       # 低重要性
freeze_channels = sorted_channels[num_zero:num_zero+num_freeze]  # 中重要性
train_channels = sorted_channels[num_zero+num_freeze:]  # 高重要性
```

### 2.2 训练阶段

```python
# ============================================================================
# SMT Training
# ============================================================================
# 只有选中的子矩阵参与反向传播
for selected_submatrix in selected_submatrices:
    # 自定义autograd: 仅计算选中块的梯度
    weight[selected_block] += lr * grad[selected_block]

# 未选中的层完全不计算梯度（requires_grad=False）


# ============================================================================
# SD-LoRA Training
# ============================================================================
# 所有维度都有forward，但处理方式不同
for param in model.parameters():
    channels = param.shape[-1]

    # Train维度: 正常梯度更新
    train_mask = torch.zeros(channels)
    train_mask[train_channels] = 1
    grad[train_channels] *= train_mask

    # Freeze维度: 梯度清零
    grad[freeze_channels] = 0

    # Zero维度: 梯度清零 + 权重设为极值
    grad[zero_channels] = 0
    param.data[:, zero_channels] = zero_value  # GLA: -100
```

## 5. 优缺点对比分析

### 5.1 SMT的优点

| 优点 | 说明 |
|------|------|
| **零推理开销** | 直接修改原权重，不像LoRA需要额外计算 |
| **持续改进** | 无平台期，增加参数持续提升性能 |
| **自动分配** | 不同层自动获得不同数量的可训练参数 |
| **部分反向传播** | 真正减少计算量 |
| **更高性能** | 在相同参数量下优于LoRA/DoRA |

### 5.2 SMT的缺点

| 缺点 | 说明 |
|------|------|
| **固定子矩阵大小** | 256×256可能不是最优 |
| **静态选择** | 训练中不更新子矩阵选择 |
| **不支持所有架构** | 主要针对Transformer设计 |
| **实现复杂** | 需要自定义autograd.Function |

### 5.3 SD-LoRA的优点

| 优点 | 说明 |
|------|------|
| **灵活粒度** | Channel级别，适应不同维度 |
| **三类设计** | Zero可以有效"遗忘"不重要的知识 |
| **GLA专用** | 针对GLA的gate机制设计 |
| **简洁实现** | 基于现有的PEFT框架 |

### 5.4 SD-LoRA的缺点

| 缺点 | 说明 |
|------|------|
| **完整反向传播** | 虽然masking但仍需计算全部梯度 |
| **激活存储** | 需要保存完整激活 |
| **比例固定** | 每层的Train/Freeze/Zero比例相同 |

## 6. 对GLA架构的适配差异

### 6.1 GLA vs Transformer Attention

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    Transformer Attention vs GLA                           │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  Transformer:                                                               │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  Attention(Q, K, V) = softmax(QK^T/√d_k) @ V                         │   │
│  │                                                                     │   │
│  │  特点: softmax饱和 → Q/K梯度小 → V梯度大                            │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  GLA:                                                                       │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  gk = F.logsigmoid(gk) / gate_logit_normalizer                       │   │
│  │  decay = exp(-exp(gk) @ Δ)                                            │   │
│  │  y = Attention(Q, K, V) × decay                                      │   │
│  │                                                                     │   │
│  │  特点: logsigmoid → 梯度行为与softmax不同                            │   │
│  │       gk_proj控制状态衰减，类似"遗忘门"                              │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 6.2 Zero值的语义差异

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        Zero值的语义差异                                    │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  SMT: (实际上没有Zero类别，只有选中和未选中)                               │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  未选中 = 冻结 = requires_grad=False                                │   │
│  │  选中   = 可训练 = 正常更新                                          │   │
│  │                                                                     │   │
│  │  没有"主动遗忘"的机制                                               │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  SD-LoRA:                                                                   │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  Zero = 设为极值 (-100)                                               │   │
│  │                                                                     │   │
│  │  对于GLA的gk_proj:                                                  │   │
│  │  gk = -100 → logsigmoid(-100) ≈ 0                                 │   │
│  │  decay = exp(-exp(0) @ Δ) = exp(-1 @ Δ) ≈ 0                       │   │
│  │  → 状态完全衰减 → "主动遗忘"该维度的记忆                            │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 9. 融合可能性探讨

### 9.1 SMT化SD-LoRA

```python
# 可能的融合方向: 在SD-LoRA中引入SMT思想

# 1. 全局channel选择 (替代固定比例)
# 原来: 每层 Train=40%, Freeze=50%, Zero=10%
# 改进: 所有channels排序，Top-40%为Train，次50%为Freeze，末10%为Zero

def select_channels_globally(all_channel_grads, train_ratio=0.4):
    all_channels = []
    for (module, layer), grad_dict in all_channel_grads.items():
        for ch, grad in grad_dict.items():
            all_channels.append((grad.abs().mean(), (module, layer, ch)))

    # 全局排序
    all_channels.sort(reverse=True, key=lambda x: x[0])

    n = len(all_channels)
    train_end = int(n * train_ratio)
    freeze_end = int(n * (train_ratio + freeze_ratio))

    train_channels = [(m,l,c) for _,(m,l,c) in all_channels[:train_end]]
    freeze_channels = [(m,l,c) for _,(m,l,c) in all_channels[train_end:freeze_end]]
    zero_channels = [(m,l,c) for _,(m,l,c) in all_channels[freeze_end:]]

    return train_channels, freeze_channels, zero_channels


# 2. 部分反向传播 (SMT的核心优势)
# 需要自定义autograd.Function，类似LinearLayer_MatrixSparsity
# 但在channel级别实现

class ChannelSparseLinearFunction(torch.autograd.Function):

        ctx.save_for_backward(weight)

### 9.2 SD-LoRA化SMT

```python
# 在SMT中引入SD-LoRA的三类思想

# 原SMT: 选中=Train, 未选中=Freeze
# 改进: 选中再细分为Train/Freeze/Zero

def three_class_smt_selection(grads, train_ratio=0.4, freeze_ratio=0.5):
    # 1. 先选Top-K子矩阵 (SMT原有逻辑)
    top_blocks = select_top_k_blocks(grads, n)

    # 2. 在选中的块中再按梯度分为三类
    for (module, layer), blocks in top_blocks.items():
        block_grads = [(grad[block].abs().mean(), block) for block in blocks]
        block_grads.sort(reverse=True)

        n = len(blocks)
        train_blocks = [b for _, b in block_grads[:int(n*train_ratio)]]
        freeze_blocks = [b for _, b in block_grads[int(n*train_ratio):int(n*(train_ratio+freeze_ratio))]]
        zero_blocks = [b for _, b in block_grads[int(n*(train_ratio+freeze_ratio)):]]

        # Zero块设为极值
        for block in zero_blocks:
            weight[block] = -100  # 对GLA的gk_proj有效
```
