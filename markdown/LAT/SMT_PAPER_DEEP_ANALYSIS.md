> **论文来源**: ICLR 2025 - Fine-Tuning Large Language Models with Sparse Matrices

> **目标**: 为GLA SD-LoRA项目改进提供理论和技术参考

## 1. 核心问题定义

### 1.1 动机

SMT旨在解决三个核心问题：

1. **性能差距**: PEFT方法（如LoRA）与全量微调（FT）之间存在性能gap
2. **LoRA平台期**: 低秩适应方法的性能随着rank增加会出现饱和甚至下降
3. **计算效率**: FT的计算和内存成本过高，无法在消费级GPU上运行

### 1.2 关键观察

```
LLaMA-7B 微显存需求分解（FT）:
┌─────────────────────────────────────────────────────────────┐
│  可训练参数:     13.6 GB  (23%)                            │
│  Adam优化器状态: 40 GB    (69%) ← 主要瓶颈                 │
│  激活值:          2 GB     (3%)                            │
│  总计:            ~58 GB                                     │
└─────────────────────────────────────────────────────────────┘
```

**关键洞察**: Adam优化器占用了近70%的显存，减少可训练参数数量能大幅降低显存占用。

## 2. SMT方法论详解

### 2.1 核心思想对比

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           LoRA vs SMT 对比                                 │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  LoRA:                               SMT:                                   │
│  ┌─────────────────────────────────┐   ┌─────────────────────────────────┐ │
│  │  W = W₀ + BA (低秩分解)          │   │  W = W₀ + ΔW_M (稀疏子矩阵)     │ │
│  │                                 │   │                                 │ │
│  │  W₀: 冻结的预训练权重            │   │  W₀: 预训练权重(部分更新)       │ │
│  │  B: m×r                          │   │  ΔW_M: 稀疏梯度(仅选中的子矩阵)│ │
│  │  A: r×n                          │   │                                 │ │
│  │  r << min(m,n)                  │   │  选中的子矩阵数 << 总子矩阵数   │ │
│  └─────────────────────────────────┘   └─────────────────────────────────┘ │
│                                                                             │
│  关键差异:                                                                 │
│  • LoRA: 新增低秩适配器，增加推理开销                                      │
│  • SMT: 直接修改原权重，无推理开销                                        │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 2.2 子矩阵选择策略

SMT提供了两种子矩阵选择方法：

#### GW-Selection (Gradient-aware，默认选择)

基于Fisher Information的启发式方法，在warmup阶段收集梯度信息：

```python
# SMT的梯度信息计算
# Equation (8) from paper
F_smt,θ = (1/N) * Σ |∇_θ log p_θ(y_i|x_i)|
```

**关键设计决策**:
- Warmup迭代次数: Commonsense用100，Math10K用25
- 子矩阵大小: 256×256（LLaMA系列的最大公约数，避免余数问题）
- 默认可训练参数比例: 0.5% (z=0.5)

#### AW-Selection (Activation-aware)

受AWQ启发，基于激活分布选择子矩阵：

```python
# 激活幅度计算
Activation Magnitude for channel i = E[‖x_i‖₂]
```

**实验结果**: AW-selection表现显著差于GW-selection（Commonsense: 53.2 vs 78.7）

**平台期原因分析**:
- LoRA的低秩近似是有损的，包含大量噪声
- 增加rank同时增加了低重要性维度的权重
- SMT专注于最显著的子矩阵，包含更少噪声

```
│  ──────┼──────────────┼─────────┼─────────────────────────────│ │

│                                                                 │

└─────────────────────────────────────────────────────────────────┘
```

### 3.3 QKV中V向量的主导地位

```
V向量自动分配占比: 95.17%
```

**梯度幅度分析**:
```
V向量梯度 = Q/K向量梯度的 5-10倍
```

**原因**（Appendix C解释）:
- Attention机制中softmax的饱和效应
- QK^T/√d_k 中的 √d_k 在预训练时不够大
- 导致Q和K的梯度变小

```
Q/K Vectors 梯度小 → Softmax饱和 → 梯度消失
     ↓
Attention Score = QK^T/√d_k
当QK^T很大时，softmax输出接近[0,0,...,1,0,...,0]
     ↓
∂softmax/∂Q_i ≈ 0 (饱和状态)
```

### 4.3 Warmup阶段设计

```python
# SMT训练流程
Phase 1: Warmup (N < 100 iterations)
├── 全量前向 + 反向传播
├── 收集每个参数的梯度
├── 累积梯度信息
└── 更新模型（加速收敛）

Phase 2: Sparse Fine-tuning (N > 100 iterations)
├── 子矩阵选择已完成
├── 仅对选中子矩阵计算梯度
├── 冻结层跳过反向传播
└── 使用FusedAdam优化器
```

**Warmup迭代次数消光**（Appendix H）:
- Commonsense: 100次（最优）
- Math10K: 25次（最优）
- 过少: 梯度信息不足
- 过多: 计算浪费

## 5. Fisher Information vs SMT对比

### 5.1 理论差异

```
True Fisher Information:
F_θ = E_{x~p(x)}[E_{y~p_θ(y|x)}[∇_θ log p_θ(y|x) ∇_θ log p_θ(y|x)^T]]

Empirical Fisher (Fisher Mask):
F̂_θ = (1/N) Σ (∇_θ log p_θ(y_i|x_i))^2

SMT Gradient Information:
F_smt,θ = (1/N) Σ |∇_θ log p_θ(y_i|x_i)|

关键差异:
┌─────────────────────────────────────────────────────────────────┐
│                    │  Fisher Mask  │     SMT                   │
│  ──────────────────┼───────────────┼─────────────────────────│
│  掩码存储          │  完整tensor    │  投影到dense tensor      │
│  反向传播          │  全量          │  部分（仅选中子矩阵）    │
│  内存成本          │  ≈模型大小     │  ≈0                      │
│  计算成本          │  全量          │  z%                      │
└─────────────────────────────────────────────────────────────────┘
```

### 5.2 子矩阵选择度量消光

```
四种梯度计算策略对比 (LLaMA-7B, Commonsense):
┌─────────────────────────────────────────────────────────────────┐
│  策略           │  公式                            │  AVG     │
│  ───────────────┼─────────────────────────────────┼─────────│
│  SMT-1 (abs().mean())    │ abs().mean(dim=(1,3))  │  73.80  │
│  SMT-2 (mean().abs())    │ mean().abs(dim=(1,3))  │  78.66 ←│
│  SMT-3 (L1)              │ abs().sum(dim=(1,3))   │  75.20  │
│  SMT-4 (L2)              │ sqrt(sum(abs()**2))    │  75.51  │
│  ───────────────┴─────────────────────────────────┴─────────│
│                                                                 │
│  结论: mean().abs() 是最佳策略                                  │
└─────────────────────────────────────────────────────────────────┘
```

## 8. 论文的理论贡献

### 8.1 挑战现有假设

1. **Geva et al. (2020, 2022)**: "记忆主要存储在MLP的FFN层中"
   - SMT发现: Attention层更关键，尤其是V向量

2. **LoRA无饱和**: "增加rank能持续提升性能"
   - SMT发现: LoRA/DoRA在0.84%后出现平台期

3. **低秩近似无损**: "低秩分解能保留关键信息"
   - SMT发现: 稀疏子矩阵选择更有效

### 8.2 核心创新点

1. **部分反向传播**: 首个在PEFT中实现部分梯度计算的方法
2. **子矩阵级别选择**: 比层级更精细的粒度
3. **自动参数分配**: 不同层可以有不同比例的可训练参数
4. **零推理开销**: 不像LoRA需要额外适配器计算

## 9. 局限性与讨论

### 9.1 论文承认的局限

1. 仅研究Decoder-only架构（LLaMA系列）
2. 子矩阵大小256×256是启发式选择，可能不是最优
3. Warmup迭代次数需要针对数据集调优

### 9.2 潜在改进方向

1. **动态子矩阵选择**: 当前是静态选择，训练中不更新
2. **不同架构**: 需要在Encoder-Decoder、Mamba等架构验证
3. **子矩阵大小**: 可作为超参数搜索
4. **与量化结合**: SMT + 量化的协同效果

## 10. 对SD-LoRA的启发要点

### 10.1 可直接借鉴的设计

| SMT特性 | SD-LoRA对应 |
|--------|------------|
| GW-Selection (梯度排序) | SDLora的warmup梯度累积 |
| 子矩阵级别选择 | Channel级别选择 |
| 部分反向传播 | 可考虑实现 |
| V向量主导 | 可验证GLA的gk_proj重要性 |

### 10.2 需要警惕的差异

| SMT设计 | SD-LoRA注意事项 |
|--------|----------------|
| 针对Transformer Attention | GLA的gate机制不同 |
| 固定子矩阵大小 | Channel可变大小 |
| 仅微调Attention | SD-LoRA也针对gate |
| softmax饱和导致Q/K梯度小 | GLA的logsigmoid可能不同 |
